# System Information CLI

A Python command-line utility that displays information about the
computer's operating system and system resources.

## Features

- Operating system information
- Python version
- CPU information
- CPU utilization
- RAM usage
- Disk usage
- Current working directory
- Timestamp
- Network information

## Technologies

- Python
- psutil
- pathlib
- platform

Clone the repository and install the required dependency:

python -m pip install psutil
